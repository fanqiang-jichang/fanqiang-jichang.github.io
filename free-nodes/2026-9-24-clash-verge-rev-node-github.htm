避坑指南：你可能遇到的7个问题

  1. 连接成功但无法上网
    检查"全局路由"是否误设为"代理"。尝试切换为"配置"模式，这通常能解决90%的访问异常

  2. 电池消耗异常
    进入iOS设置→Shadowrocket，关闭"后台应用刷新"。代理加密确实会增加1-3%的耗电，但绝不至于明显影响续航

  3. App频繁崩溃
    这往往是内存不足导致。尝试关闭其他后台应用，或升级到最新iOS版本。Shadowrocket的2.1.23版已修复多数崩溃问题

  4. 订阅链接失效
    长按订阅项选择"更新"，若仍失败，可能是服务商更换了订阅系统。联系客服获取新链接时，记得要求提供备用端口

  5. 速度突然下降
    通过"节点延迟测试"功能找出响应最快的节点。注意：香港、新加坡节点通常比美国快30-50ms

  6. 无法连接公司内网
    在"设置→本地DNS映射"中添加公司内部域名解析，完美解决企业网络兼容问题

  7. 系统提示VPN配置
    这是iOS的正常提醒，所有代理应用都会触发。你可以在"设置→VPN"中查看实际连接状态

FAQ

Shadowrocket 能否自动更新订阅？
支持。Shadowrocket 可以设置定时更新周期，例如每隔 12 小时或每天自动刷新订阅链接，确保节点列表保持最新状态。这样无需手动更新即可长期稳定使用。
如何备份 Clash 配置文件？
Clash 的配置文件通常位于程序目录或配置文件夹中（如 Windows 下的 .config/clash）。用户可直接复制该 YAML 文件以备份，也可将订阅链接保存，便于后续恢复或在其他设备上同步使用。
Netch 的透明代理适合哪些应用场景？
透明代理通过 TUN 或 WinDivert 拦截系统 IP 层流量，无需配置每个应用。适合全局科学上网、在线游戏或对局域网设备统一代理的场景。
Trojan TLS 伪装如何降低被封锁风险？
通过选择真实可访问的域名并安装有效证书，Trojan 流量可完全模拟 HTTPS 请求。这样可隐藏流量特征，降低被封锁和 DPI 检测的可能性，保证节点长期可用。
Nekoray 节点订阅自动更新如何配置？
用户可添加订阅 URL，Nekoray 会定期下载并替换旧节点。这样可保证节点列表始终最新，减少手动维护，提高使用效率，同时保证网络访问稳定可靠。
VMess AEAD 加密在封锁网络中有什么优势？
AEAD 加密可以防止数据被篡改和流量特征泄露，降低被检测风险。在封锁较高的网络环境中，保证节点长期可用，提高数据传输安全性和访问可靠性，增强用户体验。
当 V2Ray 报错 inbound 没有监听，可能是哪些配置问题？
检查 inbound 配置是否包含正确的 port、protocol 与 listen 字段；确认没有端口冲突或权限问题（非 root 绑定 1024 以下端口会失败）；查看日志中具体错误信息并根据提示修复配置。
Hiddify Next 的 Web 面板有什么用途？
Hiddify Next 自带 Web 管理面板，管理员可通过浏览器管理用户、监控流量、生成订阅链接并部署节点。无需命令行操作，极大提高管理效率。
如何在 Nginx 上为 Vmess/WS 配置反向代理与 TLS？
在 Nginx 中配置 HTTPS 站点并将特定路径（如 /ray）反向代理到 V2Ray 的 WebSocket 端口，确保 proxy_set_header 设置正确（Host、X-Real-IP 等）。同时使用 certbot 获取并自动续期 TLS 证书以维护安全。
Nekoray 节点订阅失败如何处理？
首先确认订阅 URL 是否有效，并确保网络连接正常。可手动刷新或重新添加订阅链接，保证节点列表最新。结合策略组使用，确保稳定科学上网体验。
